# 战斗界面修改指南（YuansuPlan）

> 一句话结论：战斗界面**没有 Prefab、没有场景 UI**，全部由 `Assets/C#/HUD.cs` 在运行时用代码生成。
> 所以「挪位置」= 改 `Place(...)` 的最后两个参数；「改字号/颜色」= 改 `NewText(...)` 的字号和 `.color`。
> 改完切回 Unity，等它自动编译（右下角转圈）再进 Play 即可。

---

## 1. 先记住坐标系

- Canvas 参考分辨率 **1024×768**，Scaler 用 match=0.5（`UIManager.cs` → `UITheme.EnsureScaler`）。
  实际窗口是 16:9 时，屏幕逻辑宽度会变成 ~1180，所以**贴着四边的元素用边角锚点**，别写死绝对坐标。
- `Place(rt, anchor, pivot, pos, size)`：
  - `anchor` = 挂在父容器的哪个点
  - `pos` = 相对该点的偏移，**y 轴向下为负**
  - `size` = 宽 × 高
- 常用锚点：`(0,1)` 左上 · `(0.5,1)` 上中 · `(1,1)` 右上 · `(0,0)` 左下 · `(1,0)` 右下 · `(0.5,0.5)` 正中。
- ⚠️ 行高坑：本项目字体（思源黑体）行高 ≈ 字号 × 1.45，**Rect 高度必须 ≥ 字号×1.5**，
  否则文字会整行消失（不是被裁一半）。见 `HUD.NewText` 里已统一设了 `verticalOverflow = Overflow`。

## 3. Boss 信息卡（固定左上角）

- 位置：`HUD.cs` 第 587 行 `new Vector2(14, -30)` —— x 越大越靠右，y 越负越靠下。
- 宽度：常量 `BossCardW = 330`（第 53 行）；血条高 `BossBarH = 16`（第 54 行）。
- 第一行左边是名字（`bossName`，17px，元素配色）、右边是 `当前血 / 上限`（`bossHpLabel`，13px）。
- 文案与配色：`SetBoss`（670~677）—— 名字格式是「X属性 BOSS」，颜色取元素色再往白提 25%。
- 只在 Boss 出场后显示，Boss 死掉 `ClearBoss()` 自动隐藏。

## 5. 常见改法速查

- **把某块 UI 挪位置**：找到对应 `Place(...)`，改 `pos`（y 记得负数）。
- **改字号**：`NewText(父, "名字", "文案", font, 字号, 对齐)` 的第 5 个参数；同时把 `size` 的高度给到 `字号×1.5`。
- **改颜色**：`xxx.color = new Color32(r,g,b,a)`。
- **改血条长短/粗细**：改常量 `BossCardW / BossBarH`，或 `NewArtBar` 的 `fillW / fillH`。
- **改条上的数值文案**：`Update` 系列函数里 `xxx.text = ...`。
- **新增一个 UI 元素**：`NewRect`（空容器）/ `NewImage`（色块或图片）/ `NewText`（文字）→ `Place(...)` 定位，父节点传 `playRoot`。
